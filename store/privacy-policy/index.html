Sumcheck — Privacy Policy

Applies to the Sumcheck browser extension ("Sumcheck — PDF & Document to Markdown"). Last updated: August 19, 2026.

● Sumcheck does not collect, store or transmit any user data.

All document conversion happens locally in your browser. Files you convert, pages you capture, and the resulting output never leave your device. The extension makes no network requests while running, contains no analytics or telemetry, and has no server component and no accounts.

Settings and temporary storage

Your conversion settings are stored locally in your browser (chrome.storage.local) so they persist between sessions. A page you capture is held briefly in session storage so the converter tab can read it, and is discarded within five minutes. Neither is synced or transmitted.

Optional site access

If you use "Convert linked file", Chrome asks your permission for that site so the file can be fetched and converted. That request is made to the site hosting the file, by your browser, at your instruction — nothing is sent to us, because there is no "us" to send it to.

How these claims are enforced

These are properties of the code, not promises about a server — there is no server:

ClaimEnforcement
No remote codeManifest V3 content security policy (script-src 'self' 'wasm-unsafe-eval'); the build's pre-publish check fails on any remote script reference.
No runtime network requestsEvery dependency ships inside the package; verifiable by inspecting it.
No analyticsNo analytics dependency is bundled; every third-party component is listed in the package's notices file.
No broad site accessThe manifest declares no host_permissions; site access is optional and per-origin, and an automated test asserts the extension is refused page access without an explicit user gesture.

Changes

If this policy ever changes, the change will be noted here with a new date. A change that began collecting data would contradict the product's purpose; none is planned.
